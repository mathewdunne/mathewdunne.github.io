# Mathew Dunne - Portfolio Website

A personal portfolio website with a linktree-style layout, featuring an animated starfield background, Spotify integration, and social media links.

## 📦 Tech Stack

- **React 19** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool & dev server
- **Tailwind CSS 4** - Styling framework
- **Framer Motion** - Animations
- **React Icons** - Icon library
- **TanStack Query** - Data fetching (Spotify API)

## 🛠️ Development

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🌐 Deployment

Deployed to Cloudflare Pages. Deployment is configured via the Cloudflare dashboard.
